Домашний монитор — Политика конфиденциальности / Privacy Policy

1. Общие положения / General

Инструмент «Домашний монитор» — личное некоммерческое ПО одного пользователя. Оно не собирает, не хранит и не передаёт данные третьих лиц и не имеет веб-интерфейса для посторонних.

"Home Monitor" is personal, non-commercial software of a single user. It does not collect, store or transfer any third-party data and has no web interface for outsiders.

2. Данные YouTube / YouTube data

Инструмент обращается к публичному API YouTube от имени моего собственного аккаунта и запрашивает только: список каналов моих подписок и служебные поля этих каналов (название, идентификатор). Запрашивается только чтение. Полученные данные сохраняются в локальный файл на моём домашнем сервере и не покидают его.

The tool calls the public YouTube API on behalf of my own account and requests only: the list of my subscribed channels and their service fields (title, identifier). Read-only scope only. The retrieved data is stored in a local file on my home server and never leaves it.

3. Ссылка на политику Google / Google policy link

Обработка данных аккаунта Google регулируется политикой конфиденциальности Google / Processing of the Google account data is governed by the Google Privacy Policy: https://policies.google.com/privacy

4. Удаление данных / Data deletion

Локальный файл-снапшот удаляется удалением файла. Доступ инструмента к аккаунту отзывается в настройках аккаунта Google / The local snapshot file is deleted by deleting the file. The tool's access to the account can be revoked in the Google account settings: https://myaccount.google.com/permissions — после чего инструмент не сможет запрашивать данные вовсе / after which the tool can no longer request any data.
