Домашний монитор / Home notifier bot

Что это / What this is

Личный некоммерческий инструмент: раз в сутки опрашивает публичный API YouTube (только чтение, только список подписок моего собственного аккаунта) и пишет локальный файл-снапшот, который читает мой домашний сервер. Никаких веб-страниц для посторонних, никакой рекламы, никаких данных третьих лиц.

A personal, non-commercial tool: once per day it polls the public YouTube API (read-only, my own account's subscription list only) and writes a local snapshot file consumed by my home server. No web pages for third parties, no ads, no third-party data.
